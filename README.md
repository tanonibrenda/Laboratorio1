## Normas para la Presentación de Informes
Márgenes:
❖ Superior e inferior: 2,5 cm
❖ Izquierdo y derecho: 2,5 cm
Tipo de letra:
❖ Fuente: Times New Roman / Arial / Calibri.
❖ Tamaño: 12 puntos para el texto principal.
❖ Títulos: 16 puntos en negrita
❖ Subtítulos: 14 puntos en negrita.
Alineación:
❖ Justificado para el cuerpo del texto.
